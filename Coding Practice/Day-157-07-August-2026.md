# Parameterized Builds

## 🔹 Jenkins Pipeline - Parameterized
You will learn how to **create parameterized builds in Jenkins**.

pipeline {
    agent any
    parameters {
        string(name: 'ENVIRONMENT', defaultValue: 'dev', description: 'Deployment Environment')
    }
    environment {
        INSTITUTE_NAME = "Pathnex"
    }
    stages {
        stage('Checkout') {
            steps {
                git url: 'https://github.com/loxtvishu/sample-java-app.git'
            }
        }
        stage('Deploy') {
            steps {
                sh 'echo "Deploying to $ENVIRONMENT by $INSTITUTE_NAME"'
            }
        }
    }
}

# Day 07 - Automating Cloud Infrastructure with Terraform & Ansible 

## 🔹 Ansible - Setup Nginx with Custom Config

- name: Setup Nginx with Custom Config
  hosts: all
  become: yes
  tasks:
    - name: Install Nginx
      yum:
        name: nginx
        state: present
    - name: Copy custom nginx.conf
      copy:
        src: nginx.conf
        dest: /etc/nginx/nginx.conf
    - name: Start nginx service
      service:
        name: nginx
        state: started
        enabled: yes

## 🔹 Terraform - Provision EC2 with IAM Role

resource "aws_iam_role" "ec2_role" {
    name = "pathnex_ec2_role"
    assume_role_policy = jsonencode({
        Version = "2012-10-17"
        Statement = [
            {
                Action = "sts:AssumeRole"
                Effect = "Allow"
                Principle = {
                    Service = "ec2.amazonaws.com"
                }
            },
        ]
    })
}
